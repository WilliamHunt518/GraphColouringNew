\section{Methodology}\label{sec:task}
We study human--agent collaboration via an agent channel assignment task. Participants supervise a swarm of $n$ autonomous agents moving within a bounded 2D arena. Each agent must be assigned a communication channel from $\mathcal{C} = \{\text{Red},\,\text{Green},\,\text{Blue}\}$. Two agents on the same channel and within radio range of each other create an interference clash; the operator's goal is to minimise cumulative interference over the trial.

\subsection{Problem Definition}\label{sec:problem}
Let $\mathcal{A} = \{a_0, a_1, \ldots, a_{n-1}\}$ be the set of agents. Each agent $a_i$ occupies position $\mathbf{p}_i(t) \in \mathbb{R}^2$ at time $t$ and holds a channel $c_i(t) \in \mathcal{C}$, or is in the transitional state $c_i(t) = \bot$ while a pending switch propagates. Agents move semi-randomly within the arena, periodically selecting new headings and speeds drawn uniformly from $[v_{\min}, v_{\max}]$; heading changes are smooth via a limited steering rate, and agents bounce off arena walls.

The \emph{interference graph} at time $t$ is $G(t) = (\mathcal{A},\,E(t))$, where $E(t)$ is the set of all interference edges---pairs of agents within radio range of each other:
\begin{equation}
  E(t) = \bigl\{(a_i, a_j) \mid \|\mathbf{p}_i(t) - \mathbf{p}_j(t)\| \leq r_{\mathrm{link}}\bigr\}
  \label{eq:edge}
\end{equation}
where $r_{\mathrm{link}}$ is the radio link radius. We define $\mathcal{K}(t)$ as the set of all clashing pairs---edges where both agents share an active channel:
\begin{equation}
  \mathcal{K}(t) = \bigl\{(a_i,a_j)\in E(t) \mid c_i(t) = c_j(t),\;c_i(t)\neq\bot\bigr\}
  \label{eq:clash}
\end{equation}
Because only three channels are available, any clique of size $\omega(G(t)) > 3$ cannot be properly coloured: at least one clash persists regardless of assignment. These infeasible configurations arise transiently as agents cluster and are an intentional feature of the task as they require the operator to minimise rather than eliminate clashes for that period.

\subsubsection{Performance Metric}

The primary performance measure is the total clash cost over the trial of duration $T$:
\begin{equation}
  C = \int_0^{T} |\mathcal{K}(t)|\,\mathrm{d}t
  \label{eq:metric}
\end{equation}
Each simultaneously clashing pair contributes independently, so two concurrent clashes accrue twice the cost of one. All trials share the same duration ($T = 120\,\mathrm{s}$), so $C$ is directly comparable across conditions.

\subsubsection{Channel Switching}

An operator action queues a channel switch for agent $a_i$ to channel $c'$.
The switch completes after a fixed propagation delay $\tau = 3\,\mathrm{s}$:
\[
  c_i(t + \tau) \leftarrow c'
\]
Only one pending switch per agent is permitted at a time; during a switch,
$c_i(t) = \bot$ and the agent contributes no clashes.
The delay rewards anticipatory action: a switch initiated before two agents
come within $r_{\mathrm{link}}$ can resolve a would-be clash before it begins.

\subsubsection{Warning Zone}

A secondary radius $r_{\mathrm{warn}} > r_{\mathrm{link}}$ defines an
\emph{approach zone}.
Pairs within $r_{\mathrm{warn}}$ but not yet within $r_{\mathrm{link}}$ are
visually flagged in the arena, giving the operator (and the assistive agent)
advance notice.
The approach zone affords an anticipation window of approximately:
\[
  \Delta t_{\mathrm{warn}} \approx
    \frac{r_{\mathrm{warn}} - r_{\mathrm{link}}}{2\,v_{\max}}
\]
during which a switch initiated at the moment of entering the warning zone can
complete before the link forms.

\subsection{User Interface}\label{sec:ui}

The interface spans two displays.
The \emph{arena} monitor shows the live simulation: agents are rendered as labelled coloured circles; active interference links are drawn between clashing pairs; pairs in the approach zone are visually distinguished from confirmed links. The \emph{control panel} on a second monitor hosts interaction buttons, pending suggestion displays, and watch-status indicators for each agent. In windowed (single-monitor) mode the two surfaces appear as side-by-side windows.

Each trial has a \emph{setup phase} before the timer starts. In this phase, the operator assigns initial channels to all agents; switches applied during setup are instantaneous. Once the operator confirms the initial assignment, the trial begins and the timer counts to $T$.

\section{Interaction Modes}\label{sec:modes}

Each agent is at all times under one of three oversight levels, which the operator can change at any time by selecting a group (box-drag or Ctrl+click) and choosing an action. Custody assignments persist across the trial.

\paragraph{Direct.}
The operator retains full manual control. Clicking an individual agent opens a channel-selection popup; the switch is queued immediately with no assistant involvement.

\paragraph{Supervised.}
Agents under supervised custody are monitored by the assistant. When a clash involving them is detected, the assistant generates a suggested channel assignment and displays it in the control panel; the operator may inspect and modify individual assignments before applying, or dismiss the suggestion. Operators can also request a one-time suggestion for any selected group of agents.

\paragraph{Autonomous.}
Agents under autonomous custody are managed by the assistant without operator review. When a clash is detected the assistant applies a fix immediately. Operators can also apply a one-time autonomous fix to any selected group.

\medskip
When a clash arises in a connected cluster containing agents under both supervised and autonomous custody, the two subgroups are handled independently: supervised agents receive a suggestion (treating autonomous agents' current channels as fixed neighbours), and autonomous agents are assigned immediately (treating supervised agents' channels as fixed). Custody levels are not altered. A refire suppression delay of $3\,\mathrm{s}$ prevents re-suggesting for the same agents immediately after a suggestion is applied.

\section{Assistive Agent}\label{sec:agent}

The assistant applies a standard greedy graph colouring to the target set of agents. It treats both confirmed edges $E(t)$ and approach-zone pairs as interference constraints (enabling anticipatory planning), orders agents by descending constraint degree, and assigns each the first clash-free channel; where no clash-free assignment exists it selects the channel that minimises local clashes. Each per-agent assignment is then independently randomised with probability $\varepsilon$, replacing the optimal channel with one drawn uniformly from $\mathcal{C}$.

The noise parameter $\varepsilon$ controls assistant accuracy: at $\varepsilon = 0$ it is always correct; at $\varepsilon = 1$ it assigns uniformly at random. All study trials use $\varepsilon = 0.30$, yielding approximately 70\% per-agent accuracy. The assistant detects infeasibility (cliques of size $> 3$) and flags this in the suggestion display so operators know when a clash-free assignment is structurally impossible. The assistant is entirely rule-based and deterministic given the RNG seed.

\subsection{Design}

The study uses a [\textit{within/between}]-subjects design. The independent variable is \textbf{task complexity} (\textit{3 levels}): \textit{Easy} ($n=8$ agents, $v \in [7, 15]$\,px/s), \textit{Medium} ($n=12$, $v \in [7, 15]$\,px/s), and \textit{Hard} ($n=16$, $v \in [10, 20]$\,px/s). All trials share duration $T = 120\,\mathrm{s}$ and agent accuracy $\varepsilon = 0.30$. Trial order is [\textit{counterbalanced/fixed}]; the simulation seed is fixed per participant to ensure reproducibility.

\subsection{Procedure}

Each session follows a fixed sequence:
\begin{enumerate}[noitemsep]
  \item \textbf{Pre-study questionnaire.} Participants complete a demographics
        survey (age, gender, education, technology comfort, prior AI and drone
        experience).
  \item \textbf{Tutorial.} A scripted, step-by-step tutorial introduces the arena, the interference mechanic, channel switching, and all interaction tools including Watch:Suggest and Watch:Auto.
  \item \textbf{Trials.} Participants complete [\textit{N}] timed trials in
        sequence, separated by brief inter-trial summary screens.
        Each trial starts with a setup phase (initial channel assignment,
        instant switches) followed by the timed task.
  \item \textbf{Post-trial survey.} After each non-tutorial trial the
        participant completes a questionnaire battery (Section~\ref{sec:measures}).
  \item \textbf{Post-study summary survey.} After all trials, participants rate
        each scenario and reflect on their strategy in an open-ended questionnaire.
\end{enumerate}

The session lasts approximately [\textit{XX}] minutes.

\subsection{Measures}\label{sec:measures}

\subsubsection{Objective Performance}

The primary measure is $C$ (Equation~\ref{eq:metric}).
Secondary measures include:
\begin{itemize}[noitemsep]
  \item Number of distinct clash episodes ($N_{\mathrm{clash}}$);
  \item Mean and maximum clash-episode duration;
  \item Operator reaction time (elapsed time from clash onset to first switch
        action targeting the clashing agents).
\end{itemize}

\subsubsection{Interaction Behaviour}

Switch counts are disaggregated by custody level (direct, supervised, autonomous) and by trial phase (setup vs.\ in-game).
M2 suggestions are classified into quality categories based on whether the
suggestion was accepted without modification, modified before application,
cancelled, or applied to agents that subsequently clashed within
$\tau + 2\,\mathrm{s}$ (indicating the $\varepsilon$-noise had degraded the
recommendation):
\begin{itemize}[noitemsep]
  \item \textit{clean\_accepted}: feasible, applied without modification;
  \item \textit{clean\_modified}: feasible, operator changed $\geq 1$ channel
        before applying;
  \item \textit{clean\_bad\_applied}: feasible but a clash involving the same
        agents followed within the bad-suggestion window;
  \item \textit{unavoidable\_accepted/modified}: suggestion under an infeasible
        clique (clash is unavoidable), applied with or without modification;
  \item \textit{cancelled}: dismissed without action.
\end{itemize}

\subsubsection{Subjective Measures}

After each non-tutorial trial participants complete:
\begin{itemize}[noitemsep]
  \item \textbf{NASA Task Load Index (TLX)}~\cite{hart1988nasa}: six
        subscales (mental, physical, and temporal demand; performance; effort;
        frustration) on a 20-point scale; we report the unweighted mean
        (TLX$_\mu$).
  \item \textbf{Trust in the assistant}~\cite{jian2000foundations}: six items
        adapted from Jian, Bisantz \& Drury (2000) on a 7-point Likert scale.
        Two items (\textit{suspicious}, \textit{wary}) are reverse-scored; a
        composite trust score is computed as
        $\frac{\bar{x}_{\mathrm{pos}} - \bar{x}_{\mathrm{neg}} + 6}{12}\times 7$.
  \item \textbf{Technology acceptance (TAM)}~\cite{davis1989perceived}: four
        items assessing perceived usefulness, ease of use, and intention to use
        on a 7-point Likert scale; we report the mean (TAM$_\mu$).
\end{itemize}

The post-study summary questionnaire elicits per-scenario ratings of difficulty,
tool usefulness, frequency of manual intervention, and decision confidence, plus
open-ended reflections on strategy and scenario preferences.
